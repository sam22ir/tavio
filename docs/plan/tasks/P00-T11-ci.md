# P00-T11 GitHub Actions CI
Wave 1. Parallel-safe.
## Files
- `.github/workflows/ci.yml`
## Implement
- Trigger on push and on pull_request.
- Use Ubuntu, pnpm (action-setup) and Node 22 with the pnpm cache.
- Add a service `postgres:17` with env tavio/tavio/tavio and port 54329:5432, plus a health check.
- Set the env values `DATABASE_URL=postgres://tavio:tavio@localhost:54329/tavio` and `BETTER_AUTH_SECRET=ci-only-not-secret`.
- Steps: `pnpm install --frozen-lockfile`, `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm db:migrate`, `pnpm test:int`, `pnpm build`.
## Verification
Validate the YAML with `pnpm dlx @action-validator/cli .github/workflows/ci.yml`. If that isn't available, use `python3 -c "import yaml,sys;yaml.safe_load(open(sys.argv[1]))" .github/workflows/ci.yml`.
